## The Challenge
A Pune manufacturer had procurement data in Tally, production data in a legacy ERP, and sales data in a spreadsheet. Weekly management reports took 2 days to compile manually — and were already outdated by the time decisions were made.

## Our Approach
AIRIZZ built a unified data layer connecting all three systems, with automated nightly syncs and a real-time Power BI dashboard for management.

**What we built:**
- Tally API integration
- Legacy ERP connector (custom built)
- Unified data warehouse (cloud-based)
- Executive dashboard with KPIs and drill-down capability

## The Results
- Manual reporting time reduced by 80%
- Management now has real-time visibility instead of week-old data
- ₹12L in staff time reclaimed annually
- First strategic decision made using the dashboard: identified a 15% inventory reduction opportunity

## Client Quote
"For the first time, our weekly management meeting starts with data, not arguments about which spreadsheet is correct." — CEO
